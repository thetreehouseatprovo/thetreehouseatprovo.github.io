# Treehouse Provo Events

This context defines the language for a static website that helps people discover free local Treehouse Provo events in Provo, Utah.

## Audience And Events

**Attendee**:
A person looking for an upcoming Treehouse Provo event, whether they are visiting for the first time or returning.
_Avoid_: User, customer, member

**Event**:
A free local gathering hosted by Treehouse Provo in Provo, Utah.
_Avoid_: Program, activity

**Concert Night**:
An Event centered on live music that may include a band sign-up and an open-mic sign-up.
_Avoid_: Show, gig

**Event Flyer**:
The visual announcement for a specific Event, containing the information an Attendee needs to decide whether to attend.
_Avoid_: Poster, card

**Event Record**:
The editable set of information that describes one Event for publication on the website: name, description, type, date, time, and flyer reference.
_Avoid_: Event entry, event line

**Event Type**:
The category used to identify an Event: concert, party, service, game night, or other.
_Avoid_: Event category, tag

**Upcoming Event**:
An Event whose scheduled date and time have not passed and that is eligible to appear in attendee-facing listings.
_Avoid_: Active event, current event

**Sign-up**:
The act of submitting interest to participate in a Concert Night as a band or open-mic performer.
_Avoid_: Registration, application
